## Linear Regression

The first model I explored was **Linear Regression**, a fundamental Machine Learning algorithm used to predict a continuous dependent variable using one or more independent variables.

The model tries to find the best relationship between the input variables and the target variable. In its simplest form, it fits a straight line to the data using the **Ordinary Least Squares (OLS)** method, minimizing the difference between the observed and predicted values.

Once the model is trained, it can be used to make predictions for new observations. The coefficients and intercept help understand how each independent variable contributes to the prediction.

## Logistic Regression

The second model I explored is **Logistic Regression**, which is mainly used for **classification problems** rather than predicting continuous values.

Instead of predicting a numerical value such as a price, Logistic Regression estimates the probability that an observation belongs to a particular class. For example, it can be used to predict whether a customer is likely to **leave a bank or remain a customer**, based on characteristics such as age, account activity, balance or number of products used.

The model uses the **logistic (sigmoid) function** to transform the output into a probability between 0 and 1. This makes Logistic Regression particularly useful when the business problem has a binary outcome, such as *Yes/No*, *Churn/No Churn* or *Default/No Default*.

## Random Forest

Another important model explored in this portfolio is **Random Forest**. Unlike a single decision tree, Random Forest combines multiple decision trees and uses their results together to make a prediction.

For classification problems, the different trees contribute to the final class prediction, while for regression problems their predictions can be combined to estimate a numerical value.

Random Forest is useful because it can capture **non-linear relationships and interactions between variables** without requiring the relationships to be explicitly defined beforehand. For example, the risk of a customer leaving a bank might depend not only on their balance, but also on the combination of their transaction frequency, age and number of products.

## Why Start with Basic Prediction Models?

Starting with basic and interpretable models is important because Machine Learning is not only about using the most sophisticated algorithm available.

Simple models such as **Linear Regression and Logistic Regression** provide a strong foundation for understanding how variables influence predictions and how a Machine Learning workflow works from data preparation to prediction.

Random Forest represents a natural step forward because it can capture more complex patterns while still being relatively understandable compared with more advanced Machine Learning techniques.

In a real business environment, a simple model can sometimes be more useful than a highly complex one. Companies need models that can be **understood, implemented and connected to a real business problem**, not just models that produce predictions.
